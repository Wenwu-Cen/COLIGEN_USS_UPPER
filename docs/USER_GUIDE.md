## 安装和连接

Windows x64 EXE 包含 Python、界面资源、DBC 及厂商用户态 DLL。连接 CAN 设备时安装相应的 USB 驱动。若需自定义底层默认参数，可把 [viewer.toml](../config/viewer.toml) 放到 EXE 同目录。界面保存的用户设置优先。

在「设备与显示」按实车接口选硬件与协议。选好车型和探头方案，在连接后查看实车画面及状态计数。

- **CAN FD**。选「CAN」和 ZLG、TOSUN 或 VECTOR，设置实际设备、通道并匹配速率。Vector 可按设备型号选择，或使用 `CANoe 应用映射`。[型号、通道与驱动](interfaces/CAN_HARDWARE.md)
- **XCP**。选 CAN、TCP/IP 或 UDP，将「采集协议」设为 XCP。填写 CAN 请求/响应 ID 或 ECU 网络地址，导入当前固件的 ELF、MAP 或地址 JSON。[XCP 设置与变量](interfaces/XCP.md)
- **UDP / USSD**。选 UDP 和「USSD / IPC DBC」，在「UDP 设置」填写本机监听和来源 IP。默认监听 `192.168.98.123:39001`，来源 `192.168.98.233`。[UDP 接口](interfaces/UDP_INTERFACE.md)
- **17 探头 USS 以太网**。选 TCP/IP 和「USS 以太网」。在「网络设置」按发送端填写 UDP 监听或 TCP 服务地址、字节序和结构体对齐。[USS 以太网](interfaces/ETHERNET_INTERFACE.md)
- **SERIES**。选串口、波特率及帧格式。常用 `921600、8N1`，需匹配 ECU 的 USSV 二进制输出。[串口协议](interfaces/SERIAL_PROTOCOL.md)
- **LAUTERBACH TRACE32**。加载目标调试符号，开启 NETTCP RCL。默认端口 Windows `20001`、Ubuntu `20000`。远程地址在 `[trace32] host` 设置。探头方案按固件选 17 或 20。
- **RENESAS CS+**。在 Windows 打开目标工程并连接调试器。上位机连接时自动启动远程服务和内存桥。首次连接可在 CS+ Python Console 中启用远程访问。
- **REPLAY DEBUG**。使用回灌程序更新的二进制快照做单步调试。[配置与状态](RECORDING.md#pc-回灌单步调试)

17 探头协议提供点、车位、PDC 与回波，线段来自支持该字段的 20 探头方案。S20 的部分 CAN ID 在车位和点线/PDC 格式间复用，可用「图层与测距」的车位开关切换解析。

## 打开日志

点「打开日志」选 TXT、ASC 或 BLF。TXT 支持逐帧、首尾跳转和播放。ASC/BLF 支持报文回放、倍率和进度拖动。停止录制后再切换数据源。

## 时间显示与录制字段

在线时钟显示电脑的北京时间。采集数据停滞时，电脑时钟仍可更新。回放时钟随当前帧，暂停时冻结。缺少可信日期时显示相对采样时间。

顶栏可查看设备时间戳、挡位、车速和温度。温度显示按 `原始值 / 2.0 - 40` 换算为摄氏度，TXT 保留原始编码。

新 TXT 每帧在原有第一行追加两个字段：

- `SampleTime_UTC_us`：本次采集的 UTC 时间，单位微秒。CS+ / TRACE32 由后台完成完整数据帧时记录。
- `TimeStampUnit`：原始设备时间戳的单位。调试器 / TCP/IP 为 `us`，CAN 为 `ms`。

原有 `TimeStamp_1ms` 字段及 RAW / CSV 中的设备值保持兼容，不用电脑时钟覆盖原始值。历史命名与实际单位存在差异，因此新日志明确写入单位。回放再次录制时沿用原帧采样时间和单位。

旧 TXT 没有新字段时，兼容其微秒时间戳与毫秒 Unix 时间戳；没有可信日期的计数显示为相对时间。旧日志中若设备日期本身未校准，仅靠旧文件不能还原实际采集日期。

ASC 有日期头时，按日期加帧偏移还原采样时间；没有时区的日期头按本项目北京时间约定解释。无日期头时保留相对采样时间。BLF 使用记录中的 Unix 时间戳。CAN 时间与对应几何帧一起发布，避免错用后续报文的时间。

## 视图、轨迹和测距

- **跟随车辆**：默认视角，以后轴中心为视图参考，车辆方向固定。
- **固定世界坐标**：默认以首个有效后轴中心为原点，也可选择停车场内的墙角或车位角点。车辆随位姿移动和旋转，网格保持固定。默认以 **100 m × 100 m** 方框查看地图；TXT 行程能放入方框时以整段行程居中，较长的行程可拖动查看。播放时镜头保持不动。连续采集时识别设备 ODO 回零并接续地图位置和航向；整次采集观测到的点、线和车位按世界坐标保留。历史点线以可辨认的灰蓝色显示，已记录的车位轮廓保持在地图原位。TXT 跳帧后会恢复截至目标帧的地图历史。
- **显示行车轨迹**：将后轴中心走过的世界位置连成轨迹。关闭开关仅隐藏；「清空行车轨迹」清除历史，后续继续记录。
- **ODO 与转向**：顶栏显示统一为 X 向前、Y 向左的 ODO 坐标（m）和车身航向（°，左转为正）。车图用连续 ODO 表示前轮偏转和胎纹滚动。顶栏的「方向盘模拟」和车图内方向盘均按默认 16:1 转向比换算，即方向盘模拟角 = 前轮估算角 × 16（例如前轮左转 10°，方向盘模拟左转 160°）。两者均来自 ODO；短暂掉帧或单次估算为零时保留上一轮向，之后平滑过渡。没有有效 ODO 时坐标和航向显示 `—`。若要提高前轮角估算的准确性，在「车型配置」填写实车轴距。
- **后刹车灯**：在线和回放均按连续车速变化估算；明显减速时，车图两侧尾灯亮红约 250 ms，持续减速会续亮。前进和倒车都按速度大小判断。缺少车速、跳帧或在线数据中断时清除估算；该显示无法确认实际刹车踏板或灯具状态。
- 拖动画布平移，滚轮以鼠标位置为中心缩放。在固定世界坐标下点「100 m × 100 m」「适应视图」或在画布右键，重新以当前车身居中；点「近车位」可查看近处点线与库位。
- 可分别开关扇区、PDC、点、线、车位和标注。点位、线段、车位标注默认关闭，连接或切换数据源不自动开启，可在「标注」栏手动打开。在固定世界坐标下，点线和车位标注及测距都使用选定地图原点。点击「导出地图」生成覆盖整张地图的 SVG 和 CSV。
- 「设备与显示」下方「标注」栏内的「PDC 静音」可立即关闭警报声，静音时显示「PDC 已静音」，再次点击恢复。在线采集与日志播放共用开关，切换数据源时保持当前选择；每次启动默认开启声音。静音期间 PDC 图形、数据和录制继续更新。

轨迹需要有效位置与航向，不通过车速积分伪造。缺后轴参数时沿用数据原点即后轴中心的约定，有车型参数时换算后轴中心。跳帧、回退、切换源或明显位姿跳变会按规则断开/重置轨迹。[世界坐标与轨迹](reference/WORLD_MAP.md)、[坐标转换](reference/COORDINATE_SYSTEMS.md)

## 点线高光与点击快照

1. 打开「数据详情」，切换 `POINT` 或 `LINE`。
2. 点击数组元素或其字段：黄色高光对应实时点/线，青色虚线保存点击时的几何位置。
3. 「点击快照」并排显示点击值与实时值，变化字段着色，便于观察坐标、ObjID/cNum、收发探头等异常。
4. 实时元素暂时消失时快照仍保留；再次点击或点击「更新」重新采样，「清除」删除快照。

实时跟踪以数组下标为准，下一帧可能对应其他目标，需结合 ObjID/cNum 判断。世界视角中的冻结几何保留点击时世界位置。固定地图可独立记录整次采集的点、线和车位。

## 车型、探头和本机设置

「车型配置」支持车长/车宽、轴距/悬长、数据原点、探头位置/角度/FOV/启用状态，多车型及 JSON 导入导出。「跟随在线 / 日志数据」使用源中的车型，手动选定车型用于指定安装参数。[车型说明](reference/VEHICLE_PROFILES.md)

Windows 设置位于 `%APPDATA%/COLIGEN_USS_UPPER/`，Ubuntu 设置位于 `$XDG_CONFIG_HOME/coligen-uss-upper/`，未设 XDG 路径时使用 `~/.config/coligen-uss-upper/`。`COLIGEN_CONFIG_DIR` 可隔离车型、网络、串口、硬件和数据详情布局。用户目录还保存 `more_panel_state.json`，记录详情面板的可见性与树节点展开状态。已有的源码目录布局文件会在用户目录尚无布局时读取，并在下次保存时写入用户目录。

## 常见问题

- **连接后没有数据**。检查驱动、接线、CAN 通道与速率，或网络监听地址、端口和来源 IP。XCP 还需核对当前固件的变量文件。
- **车体或点线位置异常**。检查车型原点、后轴参数及发送端轴向与单位。[坐标与单位](reference/COORDINATE_SYSTEMS.md)
- **采集正常，配对数为零**。查看依赖完整周期、实车结果与回灌计数，按项目查 [S20 录制排查](RECORDING.md#s20-录制排查) 或 [D4M3 数据合同](RECORDING.md#数据合同)。
