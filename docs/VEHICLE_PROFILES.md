# 车型与探头安装配置（v3.10.0）

Windows 11 与 Ubuntu 使用同一套配置界面。点击顶部「车型配置」打开编辑器；打开「设备与显示」后，可在「车型与探头」中快速切换已保存车型。

## 建立车型

1. 初次使用显示「跟随在线 / 日志数据」。连接设备后可从实际车身尺寸、已有探头位置开始配置。
2. 点击「复制当前为新车型」，填写车型名称、车长、车宽、数据原点距车尾。轴距、前悬和后悬可全为 0；填写后应满足三者之和等于车长，允许 1 mm 误差。
3. 在「探头安装」选择一行，编辑 X / Y / Z、朝向、回波 FOV、PDC 角和启用状态。支持新增、删除安装点，最多 64 个。
4. 点击「保存并使用」。主画布立即使用新尺寸与安装参数，重启后保留当前选择。

坐标为 X 向前、Y 向左、Z 向上，位置单位 mm；0° 朝前，+90° 朝左，±180° 朝后。预览为平面图，Z 保存为安装高度。

接收通道通过探头名称匹配。FLS / FLC / FLM / FRM / FRC / FRS 和 RLS / RLC / RLM / RRM / RRC / RRS 对应现有回波与 PDC 调试通道；额外名称用于显示安装点。物理探头方案不等于导出的调试通道数，17 探头固件当前导出 12 路回波 / PDC。

手动选定车型后，在线车辆参数和打开日志不会覆盖它。切换回「跟随在线 / 日志数据」后恢复最新数据车型。安装参数只影响上位机显示和告警筛选，不写入 ECU，不改变接收报文的坐标原点。停用探头后隐藏安装点及其回波 / PDC，并过滤该通道的声音。

## 保存与交换

「导出 JSON」保存当前编辑内容；「导入 JSON」载入待编辑内容，点击「保存并使用」后生效。同名导入需改名，避免覆盖已有车型。取消或 Esc 不保存草稿。

车型库与程序版本分开存放：

- Windows：`%APPDATA%\COLIGEN_USS_UPPER\vehicle_profiles.json`
- Ubuntu：`~/.config/coligen-uss-upper/vehicle_profiles.json`（遵循 XDG_CONFIG_HOME）
- 验证环境可用 `COLIGEN_CONFIG_DIR` 指定独立目录。

原子写入避免保存中断破坏原文件。损坏的车型库在下一次成功保存时备份为 `vehicle_profiles.invalid-<时间>.json`。

TXT 录制保存完整车型和探头参数；录制过程中切换车型也会逐帧保存。自动模式回放按帧恢复安装参数，手动模式保留操作者选择。旧日志仍可读取。

## 17 / 20 探头数据方案

在「设备与显示」选择 Lauterbach TRACE32，离线时使用「Probe Scheme」切换 17 PROBE / 20 PROBE；连接和录制期间锁定此项。选择记入同目录的 `probe_scheme.json`。

- 17 PROBE：90 点、PDC、回波和 6 个车位槽位；没有线段变量，线段开关禁用。点与车位从导出的右向 X / 前向 Y 转为画布前向 X / 左向 Y。
- 20 PROBE：保留原有 80 点及线段读取路径。
- TCP/IP 使用独立的 17 探头协议（90 点、8 个车位）；ZLG / CANoe / CS+ 使用各自原有协议。

**17 探头 PDC 外发距离为 cm。** 上位机保留 cm，到画布计算时只进行一次 cm → mm，例如输出 150 表示 150 cm，绘制半径 1500 mm。TRACE32 的 32767 表示无障碍物，不能据此拒绝整帧。原始回波 DE 距离仍按它自身协议的 mm 处理。
