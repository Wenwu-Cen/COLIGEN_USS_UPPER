## 5.3.2 · 2026-11-25 · XCP 采集方式可独立设置

- E211 的画面与回灌可分别选择轮询或 DAQ。CAN FD、TCP/IP、UDP/IP 支持混合搭配。经典 CAN 的画面支持两种方式，完整回灌使用固件快照轮询。
- XCP 设置采用通用字段名称，车型按固件变量布局自动识别。DAQ 事件和分频随采集方式启用，底部提示按行显示。
- 92 项 XCP 与 E211 协议测试、设置页回归及 Windows 自检通过。实车采集性能需在对应链路上测量。

## 5.3.1 · 2026-11-25 · E211 XCP 实车画面 DAQ

- E211 实车画面在 CAN、CAN FD、TCP/IP 和 UDP/IP 上使用动态 DAQ。经典 CAN 显示线段、车辆状态、ODO 和 PDC 故障，CAN FD 和以太网显示完整画面。
- CAN FD、TCP/IP 和 UDP/IP 的回灌输入使用独立 DAQ 列表。保留 BIN 和 JSONL 导出，CAN FD 同时导出带日期的 ASC。经典 CAN 仍采集固件回灌快照。
- 画面和回灌各自配置事件及分频。画面默认事件 1、100 ms，回灌默认事件 2、目标间隔 50 ms。实际刷新率和并发采集间隔由实车联调确认。
